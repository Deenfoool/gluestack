# Modifier Stack: политика v1

## Исходная геометрия и кеш

Стек хранит независимую исходную геометрию и дескрипторы модификаторов. Отображаемая геометрия — результат вычисления стека. Кеш промежуточных результатов переиспользует неизменённый префикс; изменение параметров, порядка или enabled-состояния пересчитывает только затронутую часть. Замена source инвалидирует весь кеш этого объекта.

Duplicate копирует source, дескрипторы и post-transform независимо от исходного объекта. Undo/Redo сохраняет source отдельно от отображаемой геометрии. `.gluestack` экспортирует source и дескрипторы; runtime GLB получает вычисленную геометрию.

Apply Transform и Origin используют матрицу после стека. Поэтому последующее изменение параметров не сбрасывает применённую трансформацию. Обе операции сначала проверяют всю выборку и готовят геометрию, затем создают одну запись Undo и изменяют объекты. При ошибке стека операция отказывается до изменения геометрии или transform. Skin, Morph, Instances, дочерние объекты и вырожденный transform не поддерживаются этим путём и отклоняются целиком.

Удаление последнего модификатора и Bake всего стека превращают текущий результат в обычную геометрию и удаляют source/cache/post-transform. Иначе новый стек повторно применил бы прежнюю матрицу. Apply и Clear также освобождают source и промежуточные результаты. Bake Through Here проверяет оставшийся суффикс до замены source.

## Boolean

В v1 Boolean остаётся **разрушающей операцией с Undo**, а не элементом Modifier Stack:

- поддерживаются Union, Difference и Intersect;
- выбираются ровно два обычных Mesh; активный объект — A, второй — B;
- результат заменяет геометрию A, cutter B остаётся в сцене;
- активный стек на выбранных объектах сначала требуется Apply/Clear;
- оба объекта должны иметь замкнутую two-manifold геометрию;
- multi-material, Skin, Morph, Instances и неподдерживаемые BufferAttributes отклоняются;
- пустой результат отклоняется, исходные объекты сохраняются.

Этот выбор ограничивает v1 понятной семантикой. Неразрушающий Boolean с зависимостями между объектами требует отдельной модели инвалидирования, удаления cutter и сохранения проектов.

## Проверка

Для автоматических регрессий нужны Node 22.22.2+ (ветка 22) либо Node 24.15+:

```sh
npm ci
npm test
```

`tests/modifier-stack.test.mjs` проверяет кеш, Duplicate, мировые координаты под трансформированным родителем, Undo/Redo, отказы без частичного изменения, Bake/Apply/Clear/Delete, встроенную диагностику, UV/material groups импортированного GLB и 12 циклов бинарного `.gluestack` reopen.

Это проверки DOM и геометрии без WebGL. Они не закрывают browser QA, проверку GPU-ресурсов, IndexedDB и полный пользовательский Pages flow. Эти release-gates остаются в ROADMAP.
