# Import / Export: политика v1

## Импорт

Выбирается один `.glb` или `.gltf` вместе со связанными `.bin` и текстурами. Data URI поддерживаются. Для локальных sidecar-файлов сначала проверяется путь относительно папки основного файла, затем точный путь и уникальное basename. `.` / `..`, URI-encoding и Windows-разделители нормализуются. Неоднозначные совпадения и отсутствующие файлы отклоняются до изменения проекта.

Если файл содержит несколько scenes, импортируется только default scene (либо первая scene при отсутствии явного выбора). Пользователь получает предупреждение; остальные scenes не включаются в проект. Выбор scene — отдельная будущая задача.

Импорт из редактора добавляет модель. Импорт из Home заменяет сцену только после успешного разбора и подготовки модели. Успешная замена создаёт одну запись Undo; ошибка сохраняет прежние объекты, выделение и клипы. Home сначала подключает поддержку анимаций и history.

Имена импортированных узлов получают уникальные суффиксы. Animation tracks переназначаются по исходным именам один раз: цепочка переименований не должна переключать клип на другой объект.

Для импорта через общий LoadingManager действует последовательная очередь разбора: карта URL одного набора sidecar-файлов не может подменить карту другого. Blob URL освобождаются и resolver снимается после завершения или ошибки.

## Ограничения

- GLB должен иметь версию 2, корректную длину файла и корректные выровненные chunks с первым JSON chunk. Повреждённый контейнер отклоняется до GLTFLoader.
- Required Draco / KTX2/Basis / Meshopt отклоняются: соответствующие декодеры не подключены.
- Неизвестное required extension отклоняется; в v1 используется список built-in extensions закреплённой Three.js 0.180.0.
- Неизвестное optional extension даёт предупреждение: его семантика не гарантируется при экспорте. Для optional decoder extensions полноценный fallback зависит от GLTFLoader; сохранение исходных объектов при ошибке гарантируется.
- Масштаб и оси не меняются автоматически. Экспортные профили не выполняют скрытых преобразований.

## Анимации и чистый GLB

`AnimationClip` проверяется как класс Three.js. Клипы копируются независимо для регистрации и history. Чистый GLB сохраняет Skin, Morph и animation tracks; editor/transient metadata (`gluestack*`, `__gluestack*`) удаляются только из экспортной копии. Пользовательские runtime extras сохраняются.

## Автоматические проверки

```sh
npm ci
npm test
```

`tests/import-export.test.mjs` проверяет регистрацию клипов и Undo/Redo, коллизии имён анимированных моделей, отказы без потери текущей сцены, Home import, очередь sidecar-resolver, относительные пути, повреждённые GLB и настоящий GLB round-trip Skin/Morph с воспроизведением клипов.

Также запускается реальный встроенный Import / Export Diagnostics: Camera/Point/DirectionalLight с проверкой projection/intensity/range, UV1/color/tangent, Data URI, default scene, неоднозначные sidecar и политика декодеров.

Это Node/DOM/геометрические проверки. Production Pages, GPU, реальные текстурные декодеры и полный браузерный flow остаются release-gates в ROADMAP.
