# gluestack

gluestack — браузерный 3D-редактор с интерфейсом и логикой работы, близкими к Blender. Цель проекта — создавать модели с нуля, редактировать существующие `.glb/.gltf`, работать с UV и текстурами и экспортировать готовый `.glb` прямо в браузере.

## Основное

- создание моделей из примитивов и дальнейшее mesh-редактирование;
- импорт и экспорт `.glb/.gltf`;
- Blender-подобные viewport, Outliner, Properties и горячие клавиши;
- UV Editor, материалы и PBR-текстуры;
- работа без backend: вычисления и файлы остаются в браузере;
- статическое размещение на GitHub Pages.

Текущий фундамент: Three.js + WebGL, объектный режим, transform gizmo, примитивы, импорт и экспорт GLB.
